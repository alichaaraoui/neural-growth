A neural network that learned differential growth. It never sees the growth rules. From 1,000 simulated runs it learned one thing: how a shape looks 16 iterations later, given the shape now and one step ago.

Repeating that one step grows the pattern, from any start you give it. Colour shows age: the oldest growth is dark, the newest is bright.

Compare runs the real simulator beside it from the same start, so you can see how close the network gets.

Model V6, running entirely in this browser.
